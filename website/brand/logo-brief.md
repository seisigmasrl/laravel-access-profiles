# Logo brief — Access Profiles

Request: PRJ-035.WEB.Q6 = B (owner, 2026-10-28). Sources: `../PRODUCT.md`, `../docs/taste.md`.

## Name
- Shown name: **Access Profiles** (owner). Title case, one space. No short form on the lockup.
- The package id `laravel-access-profiles` stays in code and URLs only. The word "Laravel" is not in the logo (trademark).

## What it stands for (facts from PRODUCT.md)
- Different permissions in different parts of a tenant: a tenant contains scopes; an assignment covers the whole tenant or selected scopes.
- Allow and deny rules. Any matching deny wins. Access is denied by default.
- Every assignment has validity dates and a record of who granted it and why.

## Feel
Safe, precise, calm (owner, confirmed).

## Styles and techniques (owner)
- Styles: combination, symbol.
- Techniques: geometric-grid, negative-space, monoline.
- Assignment: opus = combination:geometric-grid · astra = symbol:negative-space · argon = combination:monoline.

## Color
- Light and dark both (site follows the visitor's system). Mark must work in one color.
- One calm accent: cool blue-green or slate-blue. Neutrals for the rest.
- Avoid Laravel red as the main color (it would read as an official Laravel product).

## Type
Modern sans for the name (the site uses a modern sans + a mono for code). No serif.

## Never
- The Laravel logo or anything close to it. Any real brand's mark.
- A generic padlock, a plain key or a stock shield icon used alone.
- Mascots, gradients, glow, 3D, more than 2 colors in the mark.

## Where used
Favicon (16, 32 px), GitHub org/repo avatar, 1280×640 GitHub social preview, README header, site header, Open Graph card.

## Likes (taste only, never copy)
pestphp.com (clarity), inertiajs.com (precision), livewire.laravel.com (calm).

## Choice
- 2026-10-28: Ricardo picked **Opus — "Scoped Grid"** (round 1, combination + geometric-grid).
- The outer rounded square is the tenant. The 4 cells are scopes. One filled cell is one granted scope.
- Changes before the pack (round 2): the embedded dark-mode `<style>` was removed. On dark backgrounds use `logo-white.svg`. The letters are outlined from Manrope SemiBold 600 (OFL, Google Fonts). The lockup viewBox is trimmed to 295×64 so both side margins are equal.
- Colors: slate #1E293B, teal accent #1F6F78.
